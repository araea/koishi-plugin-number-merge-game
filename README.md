# 2048

Koishi 2048 插件，支持方向移动、多人对局和成就排行。

## 安装

```sh
yarn add koishi-plugin-number-merge-game
```

在 Koishi 中启用，并安装 `database` 服务。图片棋盘需要 `puppeteer` 服务；不可用时使用文本棋盘。

## 指令

| 指令 | 说明 |
| --- | --- |
| `2048` | 开始游戏；已有游戏时查看棋盘 |
| `2048.移动 <方向串>` | 移动，例如 `2048.移动 左左上` |
| `2048.战绩 [@某人]` | 查看生涯成就 |
| `2048.排行榜 [人数]` | 查看成就排行 |
| `2048.结束` | 由发起者结束当前游戏 |

也可发送上、下、左、右或 W、A、S、D；多个方向可连续输入。达到 2048 后会记录成就，游戏仍可继续。
